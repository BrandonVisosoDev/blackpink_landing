# 🎀 BLACKPINK Landing Page

Landing Page dedicada al grupo surcoreano **BLACKPINK**, desarrollada con HTML y CSS. El proyecto incluye diseño **responsive**, tipografías personalizadas desde Google Fonts y organización de secciones mediante **CSS Grid**.

---

## 📸 Vista general

La página contiene:
- **Header** con título principal.
- **Sección de historia** con texto e imagen ilustrativa.
- **Galería** con imágenes del grupo.
- **Listado de mejores canciones**.
- **Sección de integrantes** con fotos y datos.
- **Footer** con créditos del desarrollador.

---

## 🚀 Tecnologías utilizadas

- **HTML5**: estructura semántica.
- **CSS3**: estilos personalizados.
- **Normalize.css**: para estandarizar estilos entre navegadores.
- **Google Fonts**: tipografías como *Black Ops One*, *Gravitas One*, *Roboto Condensed*, entre otras.
- **CSS Grid & Flexbox**: para distribución y diseño responsive.

---

## 📱 Responsive Design

El proyecto está optimizado para:
- **Móviles**
- **Tablets**
- **Desktop**

Se emplearon **media queries** y **grid layouts** para garantizar una experiencia fluida en diferentes tamaños de pantalla.
